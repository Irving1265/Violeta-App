# Plan de screenshots para tiendas - Violeta

Usa este plan para preparar capturas reales cuando la app ya este instalada en simulador, emulador o telefono.

## Dispositivos minimos

### App Store

- iPhone grande: 6.7 pulgadas o equivalente moderno.
- iPhone compacto: pantalla menor o mediana para revisar legibilidad.
- iPad solo si decides marcar soporte real de iPad.

### Google Play

- Telefono Android 1080x1920 o similar.
- Telefono Android pequeno para revisar overflow.

## Pantallas necesarias

1. Login con marca Violeta.
2. Feed con reportes y filtros de zona.
3. Crear reporte con categoria, foto y ubicacion.
4. Reportes cercanos o mapa.
5. Centro de seguridad.
6. Chat o comentarios comunitarios.
7. Perfil y editar perfil.
8. Borrado de cuenta o privacidad.

## Reglas visuales

- No incluir datos personales reales.
- No incluir ubicaciones privadas reales.
- Usar una cuenta demo verificada.
- Evitar capturas con errores, loaders permanentes o contenido vacio.
- Revisar que no haya barras blancas, overflow horizontal ni botones tapados por el notch o la barra inferior.

## Comandos utiles

iOS:

```bash
cd mobile
npm run run:ios
```

Android:

```bash
cd mobile
npm run run:android
```

Despues de cada cambio visual importante, repite al menos una captura de feed, chat, perfil y crear reporte.
