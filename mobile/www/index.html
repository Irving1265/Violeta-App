Este build local existe para preparar iOS y Android mientras conectas la app a un backend publico con HTTPS.

Backend publico Sin configurar Define MOBILE_WEB_URL para cargar la app real.
iOS Listo para generar Acepta la licencia de Xcode y agrega la plataforma.
Android Listo para generar Necesitas Android Studio si quieres compilar localmente.
  1. Despliega Flask en una URL HTTPS publica.
  2. Configura MOBILE_WEB_URL.
  3. Ejecuta npm run cap:add:ios y npm run cap:sync.
  4. Abre Xcode con npm run cap:open:ios.
